# Simis Trading Platform

A professional-grade cryptocurrency trading platform with real-time charting, risk management, and direct exchange integration.

## Features

- **Real-Time Charting** — Professional candlestick charts with multiple timeframes and technical indicators
- **Risk Management** — Automated position monitoring, stop-loss, take-profit, and emergency exit
- **Exchange Integration** — Direct integration with Hyperliquid DEX for perpetual futures
- **Custom Indicators** — Extensible framework with BB, EMA, SMA, VWAP, RSI, MACD, ATR, HPDR
- **TradingView Integration** — UDF datafeed and Broker API for the TradingView Charting Library
- **Live Dashboard** — 24/7 monitoring with account overview, P&L tracking, and alerts

## Tech Stack

Python 3.14 · Flask/Dash · TradingView Charting Library · Hyperliquid SDK · SQLite · WebSocket
